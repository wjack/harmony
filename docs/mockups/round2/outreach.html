The box at the bottom

In a chat, the box at the bottom always talks to Claude. While a request waits, it asks the request view's Edit question: "What should Claude do differently?" Nobody else reads this chat, so there is no Comment mode here.

Sending asks Claude to redraft, as today. The old card folds into one quiet row, Earlier version of this request · not sent · Show, which reads in order whatever Claude does next. The new card lands at the end.

Each part Claude changed says "rewritten by Claude" with ‹ 2 of 2 ›: the request view's label and pager, in the same place. ‹ shows Claude's earlier wording of that part. What shows is what goes out; an earlier wording goes as your edit.

If you had already changed ticks or wording, they go to Claude with your message, so the redraft starts from your version.

Claude's reply here is sample text, not model output.
