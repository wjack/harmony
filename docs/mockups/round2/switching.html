Switching accounts (revised)

After a switch, every open tab moves to the same section for the new person, so you never land on someone else's chat. If you do reach an item the current person can't open (a pasted link, Back), the page says whose it is and offers to switch. Everyone in the demo is an admin now, so there's no view-only state to design.
